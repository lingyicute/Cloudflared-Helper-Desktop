Cloudflared 隧道管理器 GTK4 · libadwaita · Python

多条 Cloudflare Tunnel，
一个现代化桌面窗口搞定。

基于 cloudflared access 的隧道连接管理器：同时连接任意数量的 SSH / RDP / SMB / TCP 隧道， 内置 cloudflared 版本下载与切换，实时日志，一键启停。

多隧道并发

每条隧道一个独立进程

使用 Gio.Subprocess 管理 cloudflared 子进程，状态实时回传；端口冲突检测、失败自动提示并可直达日志。

版本管理

从官方 GitHub Releases 直装

自动识别 amd64 / arm64 / arm，多版本并存，在“最新已安装 / 系统 PATH / 指定版本”间随时切换。

现代界面

GTK4 + libadwaita

ViewSwitcher、Boxed List、Toast、Banner、深色模式自适应，完全遵循 GNOME HIG。

运行

# Debian / Ubuntu 24.04+
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1
python3 main.py

# Flatpak
flatpak-builder --user --install --force-clean build-dir \
  flatpak/uk.92li.cftm.CloudflaredTunnelManager.json

GitHub Actions

  • check — 字节编译并在 Xvfb 中导入全部模块，校验 GTK / Adw API。
  • pyinstaller — ubuntu-24.04 与 ubuntu-24.04-arm 双架构便携包。
  • flatpak — GNOME 47 运行时，输出 .flatpak 单文件包。
  • release — 推送 v* 标签时自动发布 Release 并附带所有产物。
